## 2025-02-12 - Parallelize Database Queries using Promise.all()\n**Learning:** When executing multiple independent database queries (e.g., fetching a total count and fetching paginated data), doing them sequentially creates an unnecessary bottleneck. In a typical REST API listing endpoint, this adds noticeable latency, as the second query is forced to wait for the first to complete.\n**Action:** Use `Promise.all()` to execute independent read queries concurrently. For example, when fetching lists, wrap the total `count()` and the data `select()` in a `Promise.all()` to reduce overall database latency by maximizing connection pooling throughput.
